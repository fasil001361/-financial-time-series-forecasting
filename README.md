📌 Project Description
This project aims to predict stock prices using financial time series data by combining signal processing and deep learning techniques.

The time series data is transformed into a time–frequency representation using Short-Time Fourier Transform (STFT), and a Convolutional Neural Network (CNN) is used for prediction.

⚙️ Technologies Used
Python
NumPy

Matplotlib
SciPy
TensorFlow / Keras
Scikit-learn
yFinance API
📊 Methodology
Data collection from Yahoo Finance
Data preprocessing and normalization
Conversion of time-series to spectrogram using STFT
CNN model training
Prediction of future stock prices
Performance evaluation using Mean Squared Error (MSE)
